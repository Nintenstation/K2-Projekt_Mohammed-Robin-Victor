## Sprint Review
Datum: 2026-11-18
Team: Malmö

Deltagare: Robin, Mohammed och Victor 

### Användarbehov:
Som en besökare vill jag kunna trycka på en knapp som visar en lista med fiktiva evenemang och deras detaljer, så att jag förstår om hämtningen har lyckats eller inte.
### Acceptanskriterium:
-Besökaren kan hämta fiktiva exempel på evenemang med en fungerande knapp.

-Om det inte finns några evenemang visas ett meddelande.

-Om hämtningen misslyckas får besökaren ett begripligt felmeddelande.
### Demoresultat
Det här visade vi: Knappen för att hämta fiktiva evenemang och hur evenemangen visas på sidan.

Lyckat flöde: Evenemangen hämtas och deras detaljer visas.

Felväg: Felmeddelande visas om hämtningen misslyckas.

Network: GET-anropet till API och dess statuskod.

Återstår: Inget
### Feedback
Observation, fråga eller önskemål: Det är tydligt att besökaren får återkoppling vid hämtningen.

Typ: Positiv observation.
### Nästa steg: 
Behåll tydliga meddelanden för de olika lägena.
### Observation, fråga eller önskemål:

Typ: Önskemål

Nästa steg:
